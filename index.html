About this site

Built with Three.js, zero frameworks

One HTML file, one CDN, no build step — deploy it anywhere that serves static files.

🧩 What's under the hood

The wireframe globe, orbiting satellites, connection arcs and particle atmosphere are rendered with WebGL through Three.js. The UI layer is hand-written HTML, CSS and vanilla JavaScript.
